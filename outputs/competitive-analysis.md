# Competitive Analysis — vs Huntr / Teal / Jobscan / Rezi

> 说明：官网多被 Cloudflare 拦截、Reddit API 被重置，实时评价抓取受限。以下基于产品模式与公开信息，
> 价格用「约」并会变化，上线前请自行核对 App Store / Trustpilot 最新评价。

## 一句话：他们都在「优化简历」，没人「追踪结果」

四家都帮你把简历做得更好看、更匹配关键词。但没有人回答求职者真正的问题：
**「我投了之后为什么没面试？哪个岗位真的值得投？」** 这是我们的楔子。

## 逐家拆解

### Jobscan —— ATS 关键词匹配的鼻祖
- 模式：贴简历 + JD →「match rate」+ 关键词清单，另有 LinkedIn 优化、Power Edit。
- 短板：
  1. **扫描次数付费墙**：免费额度很少，用完就催订阅，价格偏高（Premium 约 $30–50/月）。
  2. **鼓励关键词堆砌**：教你往里加词，却不管你有没有真实经历支撑——这正是招聘方最反感的包装。
  3. **不追踪结果**：只有「匹配率」，没有「投了之后有没有面试」。
  4. UI 偏旧，功能多年没有质变。
- 我们的机会：把「加关键词」换成「补证据」，并明确告诉用户「这是能力缺口还是文案缺口」。

### Teal —— 求职追踪 + 简历 + Chrome 插件
- 模式：Job Tracker（看板）+ 简历生成 + 薪资/公司情报 + 浏览器插件一键导入。
- 短板：
  1. **定价劝退**：Teal+ 曾按周计费（约 $9/周 ≈ $468/年），观感像暗模式，是高频差评点。
  2. **匹配浅**：基本是关键词高亮，不是真正的岗位-经历拟合分析。
  3. **功能臃肿**：什么都做，追踪器越来越重。
  4. **无结果归因**：能记「投了」，不能告诉你「为什么没面试」。
- 我们的机会：同样有追踪，但比它多一层「分数 vs 结果」归因；定价透明、一口价。

### Huntr —— 投递追踪看板 + 自动填充插件
- 模式：Kanban 式投递追踪 + 浏览器插件一键抓 JD/自动填表 + 简历/求职信 + 薪资洞察。Free + Pro。
- 短板：
  1. **免费版很紧**，核心功能靠付费。
  2. **AI 很浅**：简历/求职信是模板化生成，质量一般。
  3. **本质是电子表格**：录入靠手动，追踪是记流水账，没有「匹配分析」。
  4. **无结果洞察**。
- 我们的机会：主简历 + 自动打分 + 状态追踪一体，比「手动表格 + 模板」更省事、更有判断力。

### Rezi —— AI 简历生成器
- 模式：模板 + AI Writer 写 bullet + 求职信/离职信 + LinkedIn 优化。Free + Pro。
- 短板：
  1. **AI 文案套路化**：生成内容常被判「像 AI、空泛」，高赞差评常见。
  2. **重排版轻匹配**：帮你「好看」，不帮你「匹配岗位」。
  3. **没有求职追踪/结果反馈**，纯文档工具。
  4. **核心功能锁订阅**。
- 我们的机会：不替人写「漂亮空话」，而是「可溯源的证据」——每个匹配都指向简历里的真实一句。

## 四家的共同缺口（= 我们的护城河）

1. **不追踪结果**：Applied → Interview → Offer 的闭环，四家都没有。
2. **鼓励关键词堆砌**：都在优化 ATS 过筛，没人站在「招聘方要证据、不要包装」这边。
3. **付费墙/暗定价**：Jobscan 的扫描额度、Teal 的周订阅，都是差评重灾区。
4. **不诚实**：它们让你「看起来匹配」，我们告诉你「哪里真缺、哪里只是没写」。

## 为什么客户优先选我们（楔子）

- **结果归因**：唯一回答「为什么没面试」的工具——投了多少、进面几个、高分岗是否真的更容易进面。
- **反膨胀立场**：不教关键词堆砌，教「补真实证据 or 承认能力缺口」，恰好是招聘方最想要的候选人画像。
- **一口价透明**：免费版够用 + 平价订阅，直接打 Teal 的周订阅和 Jobscan 的额度墙。
- **一站式**：主简历 × 多岗位 × 打分 × 追踪 × 分享，一个界面闭环，不用在 Jobscan + Teal + Huntr 之间切。

## 可落地「利用他们不足」的功能清单

1. **关键词堆砌检测器**：标出「简历里出现但没有证据支撑的关键词」——正面狙击 Jobscan/Rezi。
2. **结果归因仪表盘**（已有雏形）：加「时间→面试率」「哪些公司/岗位更容易进面」。
3. **浏览器插件**：一键抓取 LinkedIn/Indeed JD → 自动存岗（对齐 Huntr/Teal，但接到结果闭环）。
4. **CSV 迁移导入**：支持从 Teal/Huntr 导出列表一键搬过来，撬存量用户。
5. **公开「晒分/求批」页**：贴分数和「缺什么」求反馈 → 社区 + 传播，四家都没有。
6. **透明定价页**：首页明示「无扫描额度、无周订阅」，把对手的差评变成我们的卖点。
7. **给教练/机构的 B2B 版**：合规（不评受保护特征）+ 可审计，四家 C 端工具做不了。

## 必须诚实面对的差距（我们不如它们的地方）

- 解析成熟度、ATS 词库、模板数量、浏览器插件、品牌与多年评价积累。
- 目前是启发式兜底 + 可选 AI，真实 LLM 质量与 ATS 细分还需打磨。
- 还没接支付、移动端、插件、LinkedIn 导入。

结论：**别在「简历优化」这个红海跟它们拼功能，拼「结果归因 + 反膨胀 + 透明定价」这三个它们结构上做不好的点。**
